# AI Discussion Stream

> **Система генерации живого диалога между двумя LLM с озвучкой, историей общения и возможностью использования в прямых трансляциях.**

## 📖 О проекте

**AI Discussion Stream** — это экспериментальный проект, демонстрирующий взаимодействие двух независимых языковых моделей в формате естественной дискуссии. Каждый агент обладает собственной историей сообщений, получает контекст разговора и последовательно формирует ответы, создавая эффект настоящего диалога.

В отличие от обычного чат-бота, система моделирует разговор между двумя виртуальными собеседниками. Сгенерированные реплики автоматически озвучиваются с помощью Text-to-Speech, сохраняются в виде транскрипта и могут использоваться для стримов, демонстраций или исследований поведения мультиагентных LLM.

Проект сочетает генерацию текста, синтез речи и управление диалогом в едином пайплайне.

* 🤖 Диалог между двумя независимыми AI-агентами;

# 🧠 Основные компоненты

### Agents

Модуль отвечает за создание и управление виртуальными собеседниками.

Каждый агент:

* получает историю переписки;
* формирует ответ;
* передает его второму участнику;
* поддерживает непрерывность обсуждения.

---

### Text-to-Speech

После генерации текста реплика автоматически преобразуется в аудио.

Это позволяет использовать проект без дополнительной обработки текста и делает разговор максимально естественным.

---

### Audio Player

Отдельный модуль отвечает за последовательное воспроизведение реплик, синхронизируя генерацию текста и аудио.

---

### Transcript

Каждая реплика сохраняется в отдельный файл, благодаря чему можно:

* анализировать разговор;
* повторно использовать диалоги;
* проводить исследования поведения моделей;
* создавать датасеты.

# ⚙️ Принцип работы

После запуска приложения создаются два независимых AI-агента.

Далее выполняется цикл:

1. первый агент получает контекст разговора;
2. генерирует ответ;
3. ответ преобразуется в аудио;
4. аудио воспроизводится;
5. сообщение сохраняется в историю;
6. второй агент получает обновленный контекст;
7. процесс повторяется.

Таким образом формируется непрерывная дискуссия между двумя языковыми моделями.

Цель проекта — показать, как современные языковые модели могут взаимодействовать друг с другом в формате естественной беседы.
